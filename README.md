# Вера Быстрова — сайт ведущей мероприятий

Премиальный продающий сайт (Next.js). Тёплый editorial-минимализм, GSAP-анимации,
плавный скролл, заявки уходят в Telegram.

## Стек
Next.js 15 · React 19 · TypeScript · Tailwind CSS v4 · GSAP (ScrollTrigger + SplitText) ·
Lenis · Framer Motion · Lucide Icons. Шрифты вшиты локально (Santa Maria Sans — заголовки,
Comfortaa — текст) — CDN не нужен.

## Patch 1.3 — правки без изменения дизайна

Внешний вид сайта остался прежним (v1.2). Изменены только содержание,
SEO и вес страницы.

### ⚠️ Сделать перед запуском

**1. Отозвать токен Telegram-бота.** Файл `.env.local` с рабочим токеном был
отправлен архивом и вышел за пределы твоей машины. Зайди к **@BotFather → /revoke**,
выпусти новый токен и положи его в свой `.env.local`:

```
TELEGRAM_BOT_TOKEN=новый_токен
TELEGRAM_CHAT_ID=твой_chat_id
```

Без этих значений форма не падает — показывает сообщение «напишите напрямую».

**2. Проверить ориентацию видео.** Первая ссылка уже вставлена
(`components/Gallery.tsx`, массив `VIDEOS`). Карточка сейчас рассчитана на
**горизонтальный** ролик 16:9. Если видео вертикальное (Reels / Shorts),
раскомментируй одну строку:

```ts
{
  url: "https://youtu.be/bDOY8Fj2B40?feature=shared",
  title: "Видео с мероприятия",
  vertical: true,   // ← раскомментировать, если ролик вертикальный
}
```

Второй слот пустой — вставишь ссылку, и видео встанут в два столбца.
Ссылка принимается в любом формате — `youtu.be/xxxx`, `watch?v=xxxx`, `/shorts/xxxx`: id
извлекается сам. Видео играет прямо на странице, новая вкладка не открывается.
Плеер грузится только по клику, до этого показывается обложка. Пока ссылка
пустая, карточка не выводится — вёрстка не ломается.

> Исходные `reel-1.mp4` (86 МБ) и `reel-2.mp4` (19 МБ) в сборку не входят:
> 105 МБ видео на лендинге не открываются с мобильного интернета. Залей их
> на YouTube и вставь ссылки.

### Что ещё изменилось

**Тексты.** Убран блок про владение языками (осталось четыре причины,
заголовок исправлен на «Четыре причины»). Разведены повторы: сценарий,
договор, тайминг и подрядчики теперь только в «От заявки до эмоций»;
КВН и дипломы — только в «Обо мне»; правая карточка в «Обо мне» стала
«Техника и условия» и больше не пересказывает прозу рядом.

**SEO.** Домен `verabystrova.site` задаётся в `config/site.ts` → `url`
(одно место на весь проект). Настроены title/description, Open Graph и
Twitter с картинкой 1200×630, canonical, `robots.txt`, `sitemap.xml`,
`manifest.webmanifest`, фавиконки и JSON-LD (`Person` +
`EntertainmentBusiness` + каталог из пяти услуг).

> `aggregateRating` намеренно не добавлен: размечать отзывы, которых нет
> на сайте, — нарушение правил Google. Появятся реальные отзывы — добавим.

**Вес.** Фотографии пережаты в WebP: 4.74 МБ → 0.85 МБ. Внешне не отличить,
но имена файлов теперь `.webp` — учитывай при замене снимков.
